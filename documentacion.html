Manuales de Ledyvas

Dos guías, según lo que necesites: una para empezar a usar Ledyvas hoy mismo, y otra con el detalle completo de cada módulo para quien administra el sistema.

Manual de Usuario Básico

Guía rápida para instalar, activar y usar Ledyvas en el día a día: primer inicio, cada módulo explicado paso a paso, copias de seguridad y preguntas frecuentes.

  • Usuarios y roles (Gerencia, Compra, Venta, Almacén, Contabilidad)
  • Catálogo: Destinos, Clientes, Proveedores y Productos
  • Compra Asistida y Compra real, paso a paso
  • Centro Logístico, Ventas, Inventario, Combustible y Flotas
  • Los 3 Consolidados explicados por separado, y preguntas frecuentes
Descargar Manual Básico

Manual Profesional Completo

Documentación oficial del sistema: arquitectura, lógica de negocio y reglas de cada módulo, pensada para quien administra Ledyvas o necesita entender el funcionamiento interno con detalle.

  • Arquitectura, base de datos cifrada y licencia
  • Flujo de datos completo y el motor de Fórmula por PAX
  • Cada módulo: Compra, Centro Logístico, Ventas, Combustible y Flotas
  • Sistema multiusuario y roles
  • Seguridad, revocación de licencia y roadmap
